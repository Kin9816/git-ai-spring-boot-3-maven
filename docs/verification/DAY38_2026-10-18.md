## 范围与实现

- `RecruitmentBrowserMysqlLiveIT` 启动完整生产 Spring Boot 应用、认证/JWT、MyBatis、MySQL、规则服务和官方 DeepSeek 客户端。仅限回环地址、新建 `ai_job_platform_day38_<数字>` 空库；写入测试数据前校验 MySQL 8、七表、空业务数据及种子角色。
- 通过真实 HTTP 创建两个合成账号、一个岗位、一份简历、一条投递与 75.00 分规则匹配；`sourceText` 中的 MySQL 参与规则识别，缺口为 Redis。浏览器操作前后比较七表所有行列，落盘仅保存行数与哈希。
- `frontend/tests/assistant-mysql-browser.cjs` 用本机已安装 Playwright / Chrome 启动临时 Vue/Vite 页面，代理到该随机回环 Spring 端口。**没有 API 拦截替身、模拟响应或手工注入登录令牌**。Browser 插件未列出，使用已安装 Playwright；没有安装新依赖。
- 浏览器真实登录学生和 HR，使用投递上下文发送学生首问、续问和 HR 首问。服务端 spy 调用真实适配器方法，只观测传输结果；固定问题、角色、上下文、历史、调用顺序和每轮最多三次调用均有断言。不完整回复会阻止后续调用，不自动重试。
- 模型启用和 2048 token / 30 秒预算仅属于测试进程。Node 子进程移除数据库、模型及 JWT 配置凭证，仅获得合成账号登录信息。没有真实个人简历或招聘对象发送给模型。
- Redis 指向测试独占的非 Redis 回环端口，执行已有异常降级，不接触共享缓存。结束后临时浏览器、Vite、Spring、连接池和保留端口关闭；专用合成库保留。

## 运行方法与常规验证

正常运行沿用 README。真实验收是显式 `*IT`，常规 `mvn test` 不执行，也不会外联模型。运行前需准备：

1. 本项目本机 MySQL 凭证、`DEEPSEEK_API_KEY` 均通过私有进程环境提供；不得写入仓库或公开命令。
2. 使用不带 `IF NOT EXISTS` 的 `CREATE DATABASE` 新建一个尚不存在的专用库，仅在新库执行 `docs/init.sql`（替换目标库名）及 `docs/migrations/day26-resume-source-text.sql`。绝不能对已有业务库执行初始化脚本。
3. 设置 `DB_URL` 为 `jdbc:mysql://127.0.0.1:3306/ai_job_platform_day38_<数字>?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useSSL=false`，并设置 `DB_USERNAME` / `DB_PASSWORD`。
4. 设置 `DAY38_NODE` 为 Node 可执行文件；`DAY38_PLAYWRIGHT_MODULE` 为已有 Playwright 包绝对路径；可用 `DAY38_BROWSER_EXECUTABLE` 指定已安装 Chrome。前端依赖须已安装，不增加仓库依赖。
5. 显式选择检查，结束后恢复修改过的环境变量：

```powershell
$env:ASSISTANT_BROWSER_MYSQL_LIVE_TEST = 'true'
$env:EVALUATION_SOURCE_COMMIT = git rev-parse HEAD
mvn -f backend/pom.xml '-Dtest=RecruitmentBrowserMysqlLiveIT' test
```

每次真实执行都会创建合成记录并最多调用模型三次；失败先检查私有证据，不要自动重跑或复用已非空的库。
